# **PERSONAL FINANCE MANAGEMENT SYSTEM**

A basic CLI application built to help the user add and store expenses, also generate reports on expenses , With the app havinng the potential to also plot charts on your expenses 


## 💰 Project Overview

This CLI app serves as a product for:
- **Visualzing Stored Expenses**: Visualize  your monthly expenses on charts  and get valuable insights on them 
- **Storing Expenses**: Store your expenses in CSV files and have them sent to anywhere, without expenses persisting on closing the CLI app
- **View Expenses**: View your expenses in the CLI 

## 📦 Installation & Setup

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
npm start
